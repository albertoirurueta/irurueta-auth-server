== Extension points for authentication methods

Each authentication method lives in its own package with its own `@Configuration`. Two extension points avoid editing
shared files:

* `LoginChainCustomizer` (package `login`) is a functional interface over `HttpSecurity`. Every bean of this type is
  applied to the login chain in `@Order` order.
* `LoginMethodFragment` contributes a fragment to the login page, which is `templates/login.html`.

== Users and clients
