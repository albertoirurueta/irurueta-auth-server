Project Modules

This project has declared the following modules:

Name Description
com.irurueta.authserver:test-support Shared test harness for the other modules: Testcontainers PostgreSQL and Mailpit support and the OpenAPI contract comparison of the drift tests.
com.irurueta.authserver:auth-server-parent Aggregator of the auth-server modules: OAuth 2.1 / OpenID Connect authorization server built with Spring Authorization Server, with its login, consent, MFA and account pages. Pure grouping, no sources of its own.
com.irurueta.authserver:bff-parent Aggregator of the bff modules: Backend-for-Frontend that signs a browser SPA in through the authorization server and calls the resource server on the user's behalf, so tokens never reach JavaScript. Pure grouping, no sources of its own.
com.irurueta.authserver:resource-server-parent Aggregator of the resource-server modules: JWT-protected API that validates the tokens issued by the authorization server. Pure grouping, no sources of its own.
com.irurueta.authserver:service-client-parent Aggregator of the service-client modules: non-interactive client that obtains tokens with the client credentials grant and calls the resource server. Only boot until the domain lands with the client-credentials issue (#8). Pure grouping, no sources of its own.
com.irurueta.authserver:e2e-tests End-to-end browser tests: the packaged auth-server and bff applications driven through headless Chromium.
com.irurueta.authserver:coverage JaCoCo coverage aggregation across every module with code, and the 80% line / 70% branch gate. No sources of its own.
